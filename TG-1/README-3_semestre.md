#### Contribuições Pessoais
* Aplicação do Java Spring Boot. 
<details> 
  Durante o terceiro semestre da faculdade, desenvolvi com meu grupo uma aplicação web exercendo o papel de um desenvolvedor full stack utilizando Java Spring Boot no back-end. Nesse projeto, aprofundei meus conhecimentos sobre o ecossistema Spring, aprendendo a configurar dependências via Spring Initializer, gerenciar as requisições na aplicação RESTFULL para comunicação entre o back-end e o front-end. Também participei da otimização das consultas SQL, garantindo melhor desempenho e consistência na camada de persistência. 
</details>

* Data Transfer Objects (DTO). 
<details> 
  Implementei e padronizei o uso de DTOs (Data Transfer Objects) para transporte seguro,eficiente e estruturado de dados entre as camadas da aplicação. Essa abordagem contribuiu para a desacoplagem entre entidades e controladores, promovendo uma arquitetura mais limpa e escalável. Além disso, utilizei Jakarta Bean Validation para validar automaticamente os dados recebidos, garantindo integridade e reduzindo erros de entrada no sistema. 
</details>

* Java Persistence API (JPA) e MySQL. 
<details> 
  Colaborei ativamente na configuração e utilização da JPA (Java Persistence API) para integração com o banco de dados MySQL aplicando boas práticas de mapeamento objeto-relacional (ORM). Além dos métodos padrão do Spring Data JPA como `save()`, `findById()` e `findAll()`, desenvolvi consultas personalizadas por convenção, como `findByStatusAndTipo(String status, String tipo)`, facilitando a busca de informações específicas de forma declarativa. Em casos mais complexos, utilizei consultas nativas (`@Query` com `nativeQuery = true`) para maior controle sobre o SQL, especialmente em endpoints que exigiam regras de negócio detalhadas e alto desempenho. 
</details>

* Segurança com Spring Security, JWT e Bcrypt. 
<details> 
  Fui responsável por implementar a camada de segurança da aplicação utilizando Spring Security, configurando filtros personalizados e definindo políticas de autenticação e autorização. Desenvolvi interceptadores que validam o token JWT (JSON Web Token) presente no header `Authorization`, garantindo que apenas usuários autenticados pudessem acessar rotas protegidas. Para reforçar a segurança dos dados sensíveis, implementei criptografia de senhas com BCrypt, seguindo boas práticas de segurança e conformidade com padrões modernos de autenticação. Essa estrutura proporcionou uma autenticação robusta e escalável, essencial para aplicações corporativas. 
</details>

### Hard Skills
Durante o terceiro semestre do curso, aprimorei minhas competências no desenvolvimento de APIs RESTful e stateless utilizando Java Spring Boot integrado com JPA (Java Persistence API).
Implementei consultas personalizadas (custom queries) para extração e filtragem de dados de forma eficiente, possibilitando a geração de relatórios dinâmicos e parametrizados.
Organizei a estrutura do projeto seguindo boas práticas de arquitetura em camadas, aplicando os princípios de separação de responsabilidades (controllers, services e repositories), o que tornou o código mais modular, legível e de fácil manutenção.
Aproveitei o potencial do ecossistema Spring, explorando recursos como injeção de dependências, gerenciamento de contexto e configuração via annotations, para desenvolver sistemas escaláveis, seguros e de alta qualidade.
No frontend, desenvolvi páginas em HTML e CSS, com integração direta à API via JavaScript puro (Vanilla JS).
Implementei requisições HTTP assíncronas (fetch API) para comunicação com o servidor e gerenciamento de autenticação via token JWT, garantindo o controle de acesso às rotas protegidas e a persistência segura da sessão do usuário.
Essa experiência consolidou meu domínio em integração entre front-end e back-end, comunicação cliente-servidor e segurança de aplicações web.
